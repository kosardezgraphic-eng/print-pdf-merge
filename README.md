# استودیو چاپ کوثر | Kosar Print Studio 2.0

سامانه تخصصی دسکتاپ ویندوز برای **چاپخانه‌ها و کپی‌سنترها** جهت ادغام، شیت‌بندی ماتریسی (N-Up / کارت ویزیت / لیبل)، تبدیل تصویر به PDF و **چاپ مستقیم برداری با کنترل دقیق سینی (Tray/Bin) و ابعاد میلی‌متری**.

---

## ویژگی‌های کلیدی معماری نسخه ۲.۰

1. **ورک‌اسپیس واحد سه‌پنلی (فارسی RTL، بدون مودال‌های مزاحم):**
   - **ستون راست:** لیست مجازی‌سازی‌شده (Virtualized) تک‌تک صفحات همه PDFها و تصاویر ورودی با چک‌باکس چاپ، چرخش ۹۰ درجه، تعداد تکرار، حذف و مرتب‌سازی با درگ.
   - **بوم وسط:** پیش‌نمایش زنده چندشیتی با خط‌کش فیزیکی (`mm` / `cm` / `inch`)، خطوط برش گیوتین، هشدار بیرون‌زدگی از ناحیه قابل چاپ، و جابجایی/تخلیه مستقیم خانه‌های جدول با درگ.
   - **ستون چپ:** فقط دو تب متمرکز **«چیدمان»** و **«چاپ»**.
2. **خروجی ۱۰۰٪ برداری و بدون افت کیفیت (`pdf-lib`):**
   - صفحات PDF با `embedPages` / `embedPage` به شکل کاملاً برداری (بدون رستر شدن به JPEG) جاسازی می‌شوند.
   - تصاویر `JPG` و `PNG` با بایت‌های اصلی خودشان (`embedJpg` / `embedPng`) و تصاویر `TIFF` (حتی چندصفحه‌ای)، `WebP` و `BMP` به صورت بدون افت (`PNG`) جاسازی می‌شوند.
3. **خواندن قابلیت‌های واقعی درایور ویندوز (`winspool.drv`):**
   - استخراج لحظه‌ای کاغذهای واقعی (`DC_PAPERS`, `DC_PAPERNAMES`, `DC_PAPERSIZE`)، سینی‌های تغذیه کاغذ مثل `Bypass Tray` (`DC_BINS`, `DC_BINNAMES`)، پشتیبانی دورو (`DC_DUPLEX`) و رنگی (`DC_COLORDEVICE`) از طریق `koffi` (و fallback خودکار PowerShell P/Invoke).
   - دکمه باز کردن مستقیم پنجره اختصاصی درایور پرینتر (`rundll32 printui.dll,PrintUIEntry /e /n"<Printer>"`).
4. **خط لوله چاپ نیتیو با مقیاس دقیق ۱۰۰٪ (`noscale`):**
   - تولید فایل PDF موقت با ابعاد دقیق کاغذ و ارسال از طریق `SumatraPDF` CLI با همان شناسه‌های عددی `paperkind` و `bin` خوانده‌شده از درایور + پاکسازی خودکار و تضمینی فایل‌های موقت.

## دستورات توسعه و تست

```bash
# نصب وابستگی‌ها
npm install

# بررسی تایپ‌ها (TypeScript Strict)
npm run lint

# اجرای تست‌های واحد موتور چیدمان و تولید PDF برداری (Vitest)
npm test

# اجرای محیط توسعه وب
npm run dev

# ساخت خروجی نصبی (NSIS) و پرتابل (Portable) ویندوز
npm run electron:build
```

برای جزئیات کامل نحوه قرار دادن `SumatraPDF.exe` در `resources/bin/` و ساخت فایل‌های `.exe` ویندوز، فایل [`WINDOWS_BUILD_GUIDE.md`](./WINDOWS_BUILD_GUIDE.md) را مطالعه کنید.
