THIRD-PARTY COMPONENT NOTICE — SumatraPDF
=========================================

When packaged for Windows distribution, Kosar Print Studio invokes SumatraPDF
("SumatraPDF.exe") as an independent external command-line executable via standard
OS process execution (Mere Aggregation) to spool generated PDF files to Windows
printer drivers.
